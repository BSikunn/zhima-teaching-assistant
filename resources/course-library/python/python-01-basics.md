# 变量、字符串与数值边界

课程：Python｜讲义编号：python-01-basics｜整理日期：2026-10-31

## 实验情境与目标

把成绩导入程序写对的第一步，是分清输入文本与计算数值。来自表单的一百二十分可能是一串字符，而运算需要数字。学习变量时不要仅记住赋值符号，应能说清每个变量现在指向什么值、属于什么类型，以及下一步操作是否保持业务含义。

## 概念与设计步骤

本实验使用学号、姓名与成绩三个字段，学号保留为字符串以保存前导零，成绩转为整数后检查范围。字符串切片产生新字符串，不能通过给某个字符下标赋值来修改原字符串。数值除法与整除表达不同需求，班级平均分不宜因为想要整数展示就提前采用整除；展示格式可以最后再决定。

## 可运行示例

运行环境：Python 3.12；仅使用标准库；在独立练习目录运行，避免覆盖已有文件。

```python
student_id = "0018"
name = "  小禾  ".strip()
raw_score = "87"
score = int(raw_score)
if not 0 <= score <= 100:
    raise ValueError("成绩超出范围")
message = f"{student_id}：{name}，成绩 {score}"
print(message)
print(score / 10, score // 10, score % 10)
print(student_id[:2], len(name))
assert student_id == "0018"
assert score // 10 == 8
```

## 逐步验证与结果解释

运行后第一行学号仍为零零一八，第二行分别显示八点七、八和七。姓名两端空格被去掉，字符串本身没有在原地修改，而是把返回的新值重新绑定给 name。最后两条断言把前导零与整除预期写成可执行说明；断言适合课堂自检，生产输入验证仍应像前面的 ValueError 那样显式执行。

## 常见误区

把学号转成整数再转回字符串会丢失前导零。字符串拼接不能自动把整数变成文字，建议使用格式化字符串。int('87.5') 不是四舍五入，会报格式错误。比较两个成绩字符串也不等于数值比较，例如字符顺序与数字大小有可能得出不同结论。

## 练习

把输入改成带空格的成绩、负数、超过一百分以及小数字符串，分别预测结果再运行。给消息增加通过与未通过标签。最后设计一种允许小数成绩的转换方式，并写清合法精度和分数范围。

## 验收要点与思路

通过标签可在 score>=60 时生成。小数输入可以使用 Decimal 或经过明确验证的浮点数，但不能简单删掉小数点后当整数处理。验收时说明为什么学号与成绩看起来都是数字，却选择不同类型。
