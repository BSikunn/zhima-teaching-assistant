# 分支、循环与边界数据

课程：Python｜讲义编号：python-02-control｜整理日期：2026-10-31

## 实验情境与目标

老师希望从一组原始成绩中找出第一个未及格的合法成绩，并跳过尚未登记的数据。这个任务同时涉及分支顺序、循环退出与缺失值处理。先用自然语言描述处理规则，再写循环，可以减少把无效数据当作正常成绩统计的错误。

## 概念与设计步骤

示例把 None 约定为未登记，把零到一百之间的整数视为有效成绩。检查缺失值要早于数值比较，否则拿 None 与整数比较会产生类型错误。break 表示已经找到目标，循环的 else 表示整个遍历没有通过 break 提前结束，因此适合表达未找到。列表为空时同样属于没有找到，应事先确认这是否符合产品提示。

## 可运行示例

运行环境：Python 3.12；仅使用标准库；在独立练习目录运行，避免覆盖已有文件。

```python
scores = [None, 82, 77, 59, 90]
for position, score in enumerate(scores, start=1):
    if score is None:
        continue
    if not 0 <= score <= 100:
        raise ValueError(f"第 {position} 条成绩无效")
    if score < 60:
        print(f"首个未及格：第 {position} 条，{score} 分")
        break
else:
    print("没有发现未及格成绩")
valid = [s for s in scores if s is not None]
print("已登记人数：", len(valid))
assert len(valid) == 4
```

## 逐步验证与结果解释

第一条数据被跳过，八十二与七十七通过条件检查，五十九触发输出并退出，九十分不再参与寻找。位置从一开始是为了面向读者展示，不意味着列表下标也从一开始。后面的推导式重新遍历全部成绩，因此已登记人数是四人，而不是退出前检查过的三名学生。

## 常见误区

循环的 else 与 if 的 else 对齐不同，缩进会改变含义。range 的终止边界不包含在结果中，不能照搬自然语言的闭区间。遍历列表时直接删除其中的元素可能跳过记录，筛选通常生成新列表更清楚。空列表与全是缺失值时也要有约定好的结果。

## 练习

分别使用空列表、全部及格、全部缺失值和首项未及格四组数据验证程序。再改成收集所有未及格成绩，说明为什么必须移除 break。最后把边界从六十分改成教师可配置参数。

## 验收要点与思路

收集全部结果时可向结果列表追加位置与成绩的二元组。验收除了检查输出，还要确认原列表没有被意外修改，并明确未登记人数、已登记人数与未及格人数的统计口径。
