# 列表、字典与去重汇总

课程：Python｜讲义编号：python-03-collections｜整理日期：2026-10-31

## 实验情境与目标

学习平台收到多条课程访问记录，需要保留首次访问的课程顺序，同时统计每门课程被访问几次。列表适合表达顺序，字典适合按键聚合，集合适合成员判断。选择容器不是语法偏好，而是在选择数据的身份规则、顺序规则和更新方式。

## 概念与设计步骤

本例将课程名称当作小样本的键，正式项目应改用稳定课程编号。统计字典记录次数，有序列表记录第一次见到的键；这样既能汇总，又能保留原访问顺序。Python 的字典保持插入顺序，但这里显式维护顺序列表便于初学者观察两种职责。若只是排序后的唯一课程集合，也可以使用 sorted(set(...))，但那会改变业务顺序。

## 可运行示例

运行环境：Python 3.12；仅使用标准库；在独立练习目录运行，避免覆盖已有文件。

```python
visits = ["数据库", "Python", "数据库", "Java", "Python"]
counts = {}
first_seen = []
for course in visits:
    if course not in counts:
        first_seen.append(course)
    counts[course] = counts.get(course, 0) + 1
print(first_seen)
print([(course, counts[course]) for course in first_seen])
copy_visits = visits.copy()
copy_visits.append("新课程")
assert len(visits) == 5
assert counts["数据库"] == 2
```

## 逐步验证与结果解释

首次顺序为数据库、Python、Java，次数依次二、二、一。counts.get 在键缺失时给出零，而不是先制造 KeyError。最后的 copy 产生新的列表，所以追加元素不会改变原列表长度。若列表元素本身是字典，浅拷贝仍共享内部字典，这一点需要使用嵌套数据另行验证。

## 常见误区

list.sort 返回 None，不应把返回值重新赋给原列表变量。集合不承担首次出现顺序的契约。使用可变列表作为字典键会失败，字典键需要可哈希。复制外层容器不能自动复制所有内部对象；面对嵌套结构要明确修改是否应影响原数据。

## 练习

把访问记录改成包含课程编号和名称的字典列表，按编号统计次数，并保留最新名称。再添加两门名称相同但编号不同的课程，验证不会被错误合并。最后写出按访问次数降序、编号升序的展示规则。

## 验收要点与思路

答案应通过编号表达身份，通过名称表达展示。验收需要包含空输入、重复访问和同名不同编号三类样本。解释去重依赖的键，比仅展示最后有三门课程更能证明你理解了数据结构。
