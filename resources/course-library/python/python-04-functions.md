# 函数参数、返回值与可变默认值

课程：Python｜讲义编号：python-04-functions｜整理日期：2026-10-31

## 实验情境与目标

相同的成绩判定逻辑被复制到导入页面、统计脚本和报告生成器后，规则变更很容易只改到一处。把规则写成函数可以集中表达输入和输出，但如果函数顺手修改传入列表或复用了可变默认值，代码仍然难以推理。

## 概念与设计步骤

先约定函数接收成绩序列与及格线，返回新建的未通过成绩列表。及格线采用仅限关键字参数，使调用时的业务含义更明显。记录日志的辅助函数用 None 表示调用方未提供容器，进入函数后再创建列表，从而避免各次调用意外共用同一个默认列表。参数默认值在函数定义时建立，不能把它当作每次调用都重新执行的表达式。

## 可运行示例

运行环境：Python 3.12；仅使用标准库；在独立练习目录运行，避免覆盖已有文件。

```python
def failed_scores(scores, *, pass_line=60):
    if not 0 <= pass_line <= 100:
        raise ValueError("及格线无效")
    return [score for score in scores if score < pass_line]

def add_log(message, logs=None):
    if logs is None:
        logs = []
    logs.append(message)
    return logs

source = [59, 60, 88]
print(failed_scores(source, pass_line=60))
print(add_log("首次"), add_log("再次"))
assert source == [59, 60, 88]
assert add_log("独立") == ["独立"]
```

## 逐步验证与结果解释

结果中的未通过成绩只有五十九，两次独立日志各有一条。函数没有修改 source，因此后续统计仍可以使用完整成绩。若调用方明确传入已有 logs，追加会修改那个容器，这是接口的一部分，应通过名称与文档说明。想要保持输入不变时，可在函数内部复制并返回新的容器。

## 常见误区

不要用默认空列表累积跨请求数据，除非明确设计了共享状态。没有 return 的函数返回 None，不是空列表。位置参数与关键字参数规则应在调用处清楚展示。函数可以返回多个值，实质上通常是一个元组，解包数量必须匹配。

## 练习

给函数增加分数范围检查，遇到负数或超过一百分时抛出异常，并写出四组输入的预期。再设计返回通过人数、未通过人数和平均分的函数，明确空列表时平均分使用何种表示。

## 验收要点与思路

推荐对空输入返回平均分 None，同时保留人数为零，避免用零分暗示真实平均成绩。验收应包含边界六十分、非法成绩、空序列和重复调用；只测试一次正常调用无法发现默认列表共享问题。
