# 流程控制与方法边界

课程：Java｜讲义编号：java-02-flow｜整理日期：2026-10-31

## 实验情境与目标

将成绩划分为优秀、通过、未通过三类时，条件先后顺序会影响结果。若先判断大于等于六十分，九十分学生就永远走不到优秀分支。本实验通过一个独立方法表达规则，再用循环运行边界样本，避免只拿一个中间分数验证。

## 概念与设计步骤

方法接收整数成绩并返回标签，入口先拒绝超范围值，再按照从高到低的互斥条件判断。返回值让规则可以被界面、报告或命令行复用，输出则放在调用方。循环遍历样本负责验证不同路径，不能把异常吞掉后仍显示成正常分类。本例保持方法没有修改外部状态，因此容易比较输入与输出。

## 可运行示例

运行环境：JDK 8 或更高版本；将代码保存为 Main.java，使用 javac -encoding UTF-8 Main.java 与 java Main 在独立练习目录运行。

```java
public class Main {
    static String level(int score) {
        if (score < 0 || score > 100) {
            throw new IllegalArgumentException("成绩超出范围");
        }
        if (score >= 90) return "优秀";
        if (score >= 60) return "通过";
        return "未通过";
    }
    public static void main(String[] args) {
        int[] scores = {0, 59, 60, 89, 90, 100};
        for (int score : scores) {
            System.out.println(score + ":" + level(score));
        }
    }
}
```

## 逐步验证与结果解释

保存为 Main.java 并编译运行。零与五十九输出未通过，六十与八十九输出通过，九十与一百输出优秀。把条件顺序故意反过来再跑一遍，应观察到优秀样本被过早归入通过。这个反例比单独背诵 if/else 语法更能说明有序判断的意义。

## 常见误区

for 循环的终止条件要区分小于长度与小于等于长度。增强 for 循环适合读取元素，但给循环变量重新赋值通常不会替换原数组元素。switch 的贯穿行为与具体语法有关，初学阶段不要混用新版箭头语法与传统 case 后的 break 规则。

## 练习

增加八十分以上的良好分类并补齐边界样本。再写一个方法统计通过人数，保持原数组不变。为负一与一百零一设计测试，说明应该抛异常还是返回无效标签，并保证所有调用方遵守同一契约。

## 验收要点与思路

验收需要包含每个阈值的前一分、等于阈值和后一分。方法返回标签、主方法输出的分工应清晰。非法数据不能算入未通过人数，否则统计结果会把数据质量问题误写成学生学习结果。
